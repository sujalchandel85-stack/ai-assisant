# 🤖 AI Student Assistant Website

A modern, responsive, and visually appealing multi-page website built using **HTML, CSS, and JavaScript**.
This project presents an AI-powered solution designed to help students improve their learning experience.

---

## 🚀 Project Overview

Students often struggle with:

* Managing study time
* Understanding complex concepts
* Finding reliable notes and coding help

This project introduces an **AI Student Assistant**, a concept-based web platform that helps solve these problems using AI tools.

---

## 🌟 Features

* 🧠 AI-powered learning concept
* 📄 Multi-page website (Home, About, Features, Contact)
* 🎨 Modern UI with glassmorphism design
* 🌌 Animated gradient background
* ⚡ Smooth hover and scroll animations
* 📱 Fully responsive (mobile + desktop)
* 🧭 Sticky navigation bar with effects

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Advanced styling, animations, responsiveness)
* JavaScript (interactions & smooth scrolling)
